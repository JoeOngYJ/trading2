# BTC spot/perpetual continuation D1 v2 plan addendum

This addendum supersedes only one D1-v1 gate phrase. A target candidate whose exact five-minute
entry or exit open is missing, or whose entry and exit belong to different source segments, is
counted and excluded before a label exists. It is not an invalid serialized label. The label phase
passes only if all serialized labels are exact and same-segment and the unchanged minimum counts
and 98% overall / 95% per-year coverage gates pass.

All other decisions in `BTC_SPOT_PERP_CONTINUATION_D1_PLAN.md` remain frozen unchanged under
`btc-spot-perp-continuation-information-d1-v2`.
